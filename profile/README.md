## What we build

ZenStory AI explores how AI agents can help people **write, adapt, and produce stories**—from the first idea to novels, games, short dramas, and narrated videos.

我们致力于构建开放、实用、可组合的叙事 AI 工作流，让创作者能以对话和 Agent 协作的方式完成故事创作与多媒介改编。

- **Story creation** — research, outlining, drafting, revision, and style refinement
- **Story adaptation** — turn narratives into games, short dramas, storyboards, and videos
- **Agent-native workflows** — reusable skills for Claude Code, Codex, and other coding agents
- **Open source** — transparent workflows that creators can inspect, adapt, and extend

| [**oh-story-claudecode**](https://github.com/worldwonderer/oh-story-claudecode) | An all-in-one skill pack for long- and short-form web fiction, from market research and story analysis to writing, humanization, and cover creation. |

## Build with us

Each project is designed as a practical building block rather than a closed black box. Explore the repositories, try the workflows, and open an issue or pull request in the relevant project when you have an idea to share.
