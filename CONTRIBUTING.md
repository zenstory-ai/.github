# Contributing to ZenStory AI ｜ 参与贡献

Thank you for helping improve ZenStory AI projects. Contributions in Chinese or
English are equally welcome.

感谢你参与 ZenStory AI。中文和英文贡献都同样欢迎；请优先遵循目标仓库自己的贡献说明与开发约定。

## Find the right place ｜ 选择正确的仓库

- Open the issue or pull request in the repository where the relevant code,
  skill, documentation, or asset lives.
- Search existing issues and pull requests before creating a new one.
- Discuss substantial features, behavior changes, and new dependencies in an
  issue before investing in implementation.
- Report suspected vulnerabilities privately through our
  [security policy](https://github.com/zenstory-ai/.github/security/policy).

## Make a focused change ｜ 保持改动聚焦

1. Fork the repository and branch from its default branch.
2. Follow repository-specific setup, style, and testing instructions.
3. Keep the change scoped; avoid unrelated formatting and generated-file churn.
4. Add or update tests and documentation when behavior changes.
5. Run the smallest relevant checks first, then the repository's required suite.

Do not commit credentials, tokens, private data, copyrighted source material you
cannot redistribute, or generated content that you have not personally reviewed.

If AI assisted the contribution, you remain responsible for correctness,
licensing, security, and every submitted line or asset.

## Open a useful pull request ｜ 提交高质量 PR

Explain:

- the user or maintainer problem;
- the approach and important trade-offs;
- the checks you ran and checks you could not run;
- compatibility, migration, dependency, or rollout considerations.

Keep reviewable work small when possible. Link related issues and include before
and after evidence for user-facing changes.

By submitting a contribution, you agree that it may be distributed under the
repository's license. Maintainers may request changes, suggest a smaller
follow-up, or close work that does not fit the project's direction.
