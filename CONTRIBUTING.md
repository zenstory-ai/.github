# Contributing to ZenStory AI

Thank you for helping improve ZenStory AI projects. Contributions in Chinese or
English are welcome.

## Before you start

- Open contributions in the repository where the relevant code or content lives.
- Search existing issues and pull requests before creating a new one.
- For a substantial feature, behavior change, or new dependency, open an issue
  first so the approach can be discussed.
- Report suspected vulnerabilities privately according to our
  [security policy](https://github.com/zenstory-ai/.github/security/policy).

## Making a change

1. Fork the repository and create a focused branch from its default branch.
2. Follow the repository's own development and style instructions when present.
3. Keep changes scoped. Avoid unrelated formatting or generated-file churn.
4. Add or update tests and documentation when behavior changes.
5. Run the relevant checks documented by the repository.

Never commit credentials, tokens, private data, copyrighted source material you
cannot redistribute, or generated content that you have not reviewed.

## Pull requests

Explain the problem, the chosen solution, and how the change was validated. Call
out breaking changes, migrations, external-service requirements, and any checks
you could not run. By submitting a contribution, you agree that it may be
distributed under the repository's license.

Maintainers may ask for changes, close work that does not fit the project, or
suggest a smaller follow-up. Please keep discussion respectful and constructive.
