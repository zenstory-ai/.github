# Support ｜ 获取支持

Use the issue tracker or Discussions area of the relevant repository. Choosing
the repository closest to the problem helps the right maintainers find it.

请在问题所属项目的 Issue 或 Discussions 中反馈，并尽量提供版本、环境、复现步骤和最小示例。

## Where to ask

- **Reproducible bug ｜ 可复现缺陷** — open a bug report in the affected repository.
- **Feature idea ｜ 功能建议** — open a feature request and describe the user problem.
- **Usage question ｜ 使用问题** — use Discussions when the repository enables it;
  otherwise open an issue with enough context to reproduce your setup.
- **Security vulnerability ｜ 安全漏洞** — do not open a public issue; follow the
  organization [security policy](https://github.com/zenstory-ai/.github/security/policy).

Before sharing logs, screenshots, projects, or sample stories, remove API keys,
access tokens, passwords, personal data, unpublished content, and other sensitive
information.

ZenStory AI projects are community-maintained open source software. Unless a
repository states otherwise, support is best effort and has no guaranteed
response time.
