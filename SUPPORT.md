# Support

For bugs, feature requests, and usage questions, use the issue tracker or
Discussions area of the relevant repository. Include the project version,
environment, reproduction steps, expected behavior, and a minimal example when
possible.

Please do not use public issues for security reports. Follow the organization
[security policy](https://github.com/zenstory-ai/.github/security/policy) instead.

Before sharing logs or screenshots, remove API keys, access tokens, passwords,
personal data, unpublished story content, and other sensitive information.

ZenStory AI projects are community-maintained open source software. Unless a
repository states otherwise, support is provided on a best-effort basis and no
response-time guarantee is offered.
