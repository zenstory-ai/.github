# 出处与截图

讲解文档里的每个结论，读者都应该能顺着出处找回源文件，自己看一眼。这份文件讲出处怎么写、源文件和
系统页面怎么截图、图注怎么写。下面的例子都是虚构的。

## 出处怎么写

| 对象 | 写法 | 例子 |
|---|---|---|
| 表格里的意见 | 《文件名》「页名」第 N 行，必要时加单元格 | 《核对意见.xlsx》「服务」页第 34 行 B34:C34 |
| 表格里的公式 | 《文件名》「页名」单元格 = 公式，再写保存的计算结果 | 《门店评分表 v3.xlsx》「陈列」页 H27 = AVERAGE(C27:C30)，保存值 3.5 |
| 文档里的笔记 | 《文件名》第 N 条或第 N 段 | 《店长试用笔记.docx》第 6 条 |
| 系统页面 | 环境、菜单路径、页面上的名称或编号 | 测试环境 → 评分规则 → 效率 → 客流达标 |
| 系统改动 | 一句白话，提交号放括号（文档会到外部的人手里时省掉提交号） | 投诉响应时长的单位改为小时（提交 a1b2c3d） |

规则：

- **原话逐字照录**：连原文里的笔误、多余的空格和标点也照录。整理过的跟踪表和原文不一样时，以原文为准，并说明跟踪表是转录的。
- **行号写明是哪份文件的**：跟踪表的行号和源文件的行号可能对不上（删过空行），两套都出现时注明。
- **类别、状态照源文件**：意见人自己标的类别（比如「算分」「建议」）原样写，哪怕备注的内容和类别对不上，也照录并在结论里说明。
- **数值写保存值还是重算值**：工作簿里保存的计算结果，和自己按公式重算的结果，要分开说；自己按公式重算的值标「自算」。输入是假设的，另标「假设」（见 SKILL.md 第 4 节），两个标记可以同时出现。

## 源文件怎么截图

目标是让读者看到文件**本来的样子**，不是重新排版过的表格。

1. **优先用操作系统自带的预览渲染**：例如 macOS 的「快速查看」（`qlmanage -p -o 输出目录 文件`）能把 xlsx、docx 渲染成网页，每个工作表一个页面；再用无头浏览器打开截图。先把源文件复制到临时目录再渲染，不在原处操作。
2. **只加标注，不改内容**：可以加红框、行号列标这类定位标注，图注写明「标注是后加的」；不能改单元格里的字。
3. **渲染只显示保存的结果**：公式不会出现在截图里，要讲公式就写在图注或正文里。白色字体、隐藏行这类在截图里看不见的格，在图注里说明（例：「第 18–20 行是隐藏行，截图里看不到；这三行的内容见正文表格」）。
4. **只截相关的部分**：表格很宽时只截有关的列和行，前后各留一两行上下文；跳过中间行或拼接了几段的，图注写明「中间行已略去」「两段截图拼接」。
5. **预览渲染做不到时**：按单元格原文重排成表格再截，图注写「原文摘录（据源文件读取，非截图）」。
6. **图要能投屏**：宽度足够、字能看清。小图（比如几百像素宽的缩略截图）在投屏时会糊，重截高清的。
7. **放进文档**：HTML 里用 data: URI 内嵌进 `<img>`（体积大时转 JPEG 或压缩 PNG，但不缩到看不清），不引用外部图片文件；在线文档用平台的图片块。

## 系统页面怎么截图

- **只读浏览**：截图时只看不改，不点会写数据的按钮；能拦截写请求就拦截。
- **截到要讲的那一步**：页面默认停在别的步骤、别的页签时，先点到要讲的那一处再截，否则图和正文对不上。
- **截改后的样子**：「改成了什么」配改后的页面；改前的页面已经不存在时，不要用本地临时改出来的页面冒充。
- **查一遍敏感信息**：地址栏、账号、其他客户的名字，见 SKILL.md 第 6 节。

## 图注怎么写

图注只写图里看得到的东西：文件或页面、页、行或格、红框指的是什么。

| 反例 | 问题 | 改成 |
|---|---|---|
| 「公式是三项相加」，图里只截到前两项 | 图注超出了图 | 换一张能看到整条公式的图，或者写「图中只到第二项，第三项是……」 |
| 「红框是本次改的两处」，其实改了五处 | 读者会以为另外三处没改 | 「本次改了 5 处（第 2、3、6、9、11 处），红框标出其中两处」 |
| 「金额单位是万元」，表头其实写的是「元」 | 图注把单位说错了 | 「C 列金额单位是元（见 C1 表头）」 |
| 截图里的文档已经改过，图还是旧的 | 图和现版对不上 | 源稿改了就重截，回头核对图里的关键句 |
| 「第 1 页」，其实是连续渲染的文档开头 | 页码说不准 | 「文档开头」 |
| 文件名只写「旧版表」，源文件一览里没有它 | 读者不知道是哪份 | 写全文件名和存放位置 |
