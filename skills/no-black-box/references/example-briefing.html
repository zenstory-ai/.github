1分档按试点数据重定

它是什么

评分表里有一页「分档标准」，把数字类的答案（日均客流、员工人数、开业年限……）换算成档位：每个指标列四个门槛，答案达到哪一级门槛就记哪一档，档位对应这一项的得分。

原文 / 改前

原文见上方。改前用的是上一版评分表的分档，分界值是按行业通用数据定的。

改成了什么

新表的分界值按试点门店的实际数据重新定：客流、人数的门槛普遍放低，投诉响应时长的门槛反而收紧（时长越短越严）。表里每格四个数，依次是进入第 1 到第 4 档的门槛：

指标改前改后
日均客流2000 / 1200 / 600 / 300500 / 300 / 150 / 80
员工人数80 / 40 / 20 / 1020 / 12 / 8 / 4
投诉响应时长（小时）48 / 24 / 12 / 624 / 12 / 6 / 2（时长变短，要求更严）
算给你看

一家日均客流 400 人的门店（假设）：改前在 300~600 之间，落在第 4 档，算小店；改后在 300~500 之间，落在第 2 档。同样的答案，这一项从第 4 档升到第 2 档。

再看日均客流 2500 人的门店（假设）：改前改后都超过第 1 档，结果不变，大店不受影响。

边界
  • 原来空着的档位不补。
  • 新表的「员工人数」没写兼职怎么算（按人头还是折成全职）；暂按人头算，请顾问定（确认单 待定 1）。
怎么落地
  • 共改 37 个指标、142 个档位，改后逐格与新版评分表核对一致。
影响

新提交的评分结果会变；已经出过的报告不受影响。

和其他事项的关系
  • 员工人数口径进确认单 待定 1；顾问意见表里「客流分档太高」那条已解决，列在确认单「已处理」里。
第二处：暗访未通过的门店服务维度最高 60 分，服务分原本高的店降得多；已在测试环境发布 已完成

2暗访未通过，服务分封顶

它是什么

总分由服务、陈列、卫生、效率四个维度加权而来，权重 0.4 / 0.2 / 0.3 / 0.1，这一版没变。神秘顾客暗访是顾问每季度派人扮成顾客到店，按清单记「通过 / 未通过」。

改成了什么
情形改前改后
暗访未通过服务维度按各题得分算服务维度超过 60 的记 60
暗访通过，或本季没有暗访按各题得分算不变
算给你看

某店四个维度得 82 / 60 / 70 / 90（假设），本季暗访未通过：改前总分 82×0.4 + 60×0.2 + 70×0.3 + 90×0.1 = 74.8；改后服务记 60，总分 60×0.4 + 60×0.2 + 70×0.3 + 90×0.1 = 66。

同一家店如果暗访通过（假设），改前改后都是 74.8，不受影响。

边界
  • 封顶只管服务维度；陈列、卫生、效率照旧。本季没有暗访的门店按通过处理。
影响

新评分里暗访未通过的门店服务分下降；已出报告不变。
