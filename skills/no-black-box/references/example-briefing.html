1重置分档标准

它是什么

很多题的答案是数字（日均客流、员工人数、开业年限……）。评分时拿答案和分档页比，看落在第几档，档位决定这一项得几分。

原文 / 改前

原文见上方。改前用的是上一版评分表的分档，按大型门店的规模设定。

改成了什么

分界值整体调低，从「大型门店的尺度」调到「社区门店的尺度」。四个数是第 1 档到第 4 档的分界：

指标改前改后
日均客流2000 / 1200 / 600 / 300500 / 300 / 150 / 80
员工人数80 / 40 / 20 / 1020 / 12 / 8 / 4
投诉响应时长（小时）48 / 24 / 12 / 624 / 12 / 6 / 2（这一项是收紧）
算给你看

一家日均客流 400 人的门店（假设）：改前在 300~600 之间，落在第 4 档，算小店；改后在 300~500 之间，落在第 2 档。同样的答案，这一项从第 4 档升到第 2 档。

再看日均客流 2500 人的门店（假设）：改前改后都超过第 1 档，结果不变，大店不受影响。

边界
  • 原来空着的档位不补。
  • 「停车位数量」新表少了一行，按位置贴错了数量级，保留原值，交顾问确认。
怎么落地
  • 每个分界值在系统里有多份副本（不同模块各引用一次），全部一起改。
  • 共改 37 个指标、142 个档位；第一版漏了两个模块的副本，比对时发现后补齐。
影响

新提交的评分结果会变；已经出过的报告不受影响。

和其他事项的关系
  • 停车位那一项进确认单 Q-3；顾问意见表里「客流分档太高」那条已解决。
第 2 条：四个维度改成一样重，效率分高的店受益、服务分高的店吃亏；已在测试环境发布 已完成

2权重重置为等权

它是什么

总分由几个维度加权平均而来：服务、陈列、卫生、效率。权重就是每个维度占多大比重。

改成了什么
维度改前改后
服务 / 陈列 / 卫生 / 效率0.4 / 0.2 / 0.3 / 0.10.25 / 0.25 / 0.25 / 0.25
算给你看

某店四项得分 80 / 60 / 70 / 90（假设）：改前 80×0.4 + 60×0.2 + 70×0.3 + 90×0.1 = 74；改后四项平均 = 75。效率分高的店受益，服务分高的店吃亏。

边界
  • 原来空着的权重不补；为 0 的（表示不参与）保持 0，所以参与计算的维度不变，只变比重。
影响

新评分结果会变，已出报告不变。
