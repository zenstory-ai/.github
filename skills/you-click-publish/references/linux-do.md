# linux.do

linux.do 基于 Discourse。社区重视真诚和人味，格式越像 AI 生成越容易被反感。

## 开源推广帖

推广开源项目时，社区要求在正文最上方放一段声明，并打上「开源推广」标签。照抄下面的模板，**每一项「是/否」由发帖人自己决定**，Agent 不代为承诺：

```markdown
#### **本帖使用社区开源推广，符合推广要求。我申明并遵循社区要求的以下内容：**

* **我的帖子已经打上 #开源推广::tag 标签：** 是
* **我的开源项目完整开源，无未开源部分：** 是
* **我的开源项目已链接认可 LINUX DO 社区：** 是
* **我帖子内的项目介绍，AI 生成、润色内容部分已截图发出：** 是
* **以上选择我承诺是永久有效的，接受社区和佬友监督：** 是

*以下为项目介绍正文内容，AI 生成、润色内容已使用截图方式发出*

---
```

注意：

- 第三项要求项目已链接认可 LINUX DO 社区。发帖前检查被推广的仓库 README 里有没有致谢，没有就先补（放在仓库根目录 README，措辞和组织内其他项目一致）。
- 第四项和 AI 写作直接相关。正文是 Agent 起草的，要明确告诉发帖人这一点，由他决定是改成截图发，还是他已经改写成自己的文字。

## 排版

- 声明块之后才是正文。正文段落之间空一行（Discourse 的 Markdown），链接单独一行，会自动展开成卡片。
- 正文少用标题、粗体、引用块；不用「」；不做头图。
- 参考发帖人以前的帖子：用 `https://linux.do/raw/<topic_id>/1` 看原始 Markdown，照着它的分类、标签和排版来。

## 在编辑器里填草稿

前提：浏览器里已登录发帖人的账号。遇到 Cloudflare 验证，请人自己勾选。

1. 打开目标分类页（例如 `/c/develop/4`），点「新建话题」(`#create-topic`)。
2. 点标题框 `#reply-title`，输入标题。
3. 点正文框 `.d-editor-input`，**一次性粘贴**整段正文（设置值，不要逐字输入，否则列表会被自动续写打乱）。
4. 核对：正文框的值与定稿文件逐字一致；右侧预览 `.d-editor-preview` 里出现了声明和正文。
5. 分类：确认 `.category-chooser` 是预期分类，不对就点开选择。
6. 标签：点 `.mini-tag-chooser`，在搜索框输入标签名，选中对应的那一项（同名标签可能有多个，注意「不能用于此类别」的提示）；全部选好后按 Esc 关闭。
7. 截图交给发帖人。编辑器右上角可能弹出「您的话题类似于…」浮层，提醒他关掉即可。
8. **停在「创建话题」按钮前**，由发帖人点击发布。

不要用 `/new-topic?title=…&body=…` 把整篇正文塞进网址预填：网址一长就会被风控拦截，并可能连累后续请求。
