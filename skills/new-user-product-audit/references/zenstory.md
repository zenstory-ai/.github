# ZenStory 产品档案

分两部分。**第一部分「运行须知」开跑前读**，只包含环境、访问方式与安全边界，不剧透产品
怎么用。**第二部分「产品事实」首轮体验结束后才读**，用来在第二轮核对：首轮的困惑哪些是
产品没讲清，哪些是设计如此。

---

## 第一部分：运行须知（开跑前读）

### 环境

| 环境 | 官网 | 应用 | 说明 |
|---|---|---|---|
| production | `https://zenstory.ai` | `https://app.zenstory.ai` | 真实用户在用；**需要操作者明确授权** |
| staging | — | `https://app-preview.zenstory.ai` | 受 Vercel Deployment Protection 保护 |

`zenstory.ai` 是组织官网（同时介绍开源写作工具），从那里链到应用；应用根地址本身也有一个
未登录首页。到达阶段两条入口都走：先从 `zenstory.ai` 点进应用（看官网对应用的介绍与跳转是否
顺），再单独看应用未登录首页的五秒测试。staging 没有对应官网，只看应用首页，并在报告里注明。

### 访问 staging（Vercel 保护）

直接打开会落到 Vercel 登录/保护页。两种方式，**都不要把令牌打印、写进日志或截图**：

- HTTP 请求（健康检查、看接口响应）：用 `vercel curl` 代替 `curl`。
- 浏览器：用 `vercel env run` 注入短期 OIDC 令牌，作为按源限定的请求头带上：

```bash
# 在已 link 到 ZenStory web Vercel 项目的目录里执行
vc env run -- sh -c \
  'test -n "$VERCEL_OIDC_TOKEN" && AGENT_BROWSER_SESSION="$2" agent-browser open "$1" \
     --headers "{\"x-vercel-trusted-oidc-idp-token\":\"$VERCEL_OIDC_TOKEN\"}"' \
  sh https://app-preview.zenstory.ai novelist          # 末尾是 persona 短名
```

之后在同一个 session 里继续操作。请求头名必须是 `x-vercel-trusted-oidc-idp-token`，不要换成
`x-vercel-oidc-token`。令牌过期（又落到保护页）就重新执行上面这条。

### 账号

- production：用一次性邮箱真实注册（见 [disposable-inbox.md](disposable-inbox.md)）。注册页若出现
  邀请码字段，记录它是否可选、说明是否清楚，不要向任何人索要邀请码。
- staging：可用操作者提供的预验证测试账号文件（通常在运行目录之外、权限 0600）；用它时
  报告里把「注册与验证」标为未覆盖。
- 昵称 `audit-<persona>-<YYYYMMDD>`，项目名加 `[audit]` 前缀。

### 安全边界（本产品特有）

- 支付走支付宝：**任何情况都不扫码、不付款**；看到支付页即停，记录到这一步为止的体验。
- 免费额度按北京时间自然日计算；一个 persona 用完当天额度就停，不要换号绕过额度来“多测一点”
  （除非操作者要求测多账号场景）。
- 不在「反馈 / 联系我们 / 客服邮箱」里发测试内容。
- 结束时删除测试项目，或保留并在报告附录里列出项目名。

## 第二部分：产品事实（首轮体验结束后才读）

### 定位

AI 辅助的小说创作工作台：以「文件」为中心（大纲、正文、角色、设定等），通过与 AI 对话
来生成和修改内容。面向网文作者、短篇作者与短剧编剧。

### 项目类型

| 类型 | 适合的场景任务 |
|---|---|
| 长篇小说 | 开书、大纲、连续写章节、续写 |
| 短篇小说 | 一篇完整短篇（数千到一两万字） |
| 短剧剧本 | 短剧大纲、分集剧本 |

### 工作区

三栏布局：**左侧文件树**（项目里的大纲、正文、角色、设定等文件）、**中间编辑器**（编辑当前
文件，自动保存，有版本历史）、**右侧 AI 对话**（Agent 会读取项目文件、创建或修改文件，并以
流式方式展示进度）。手机上三栏会折叠，需要切换面板。

核对点：AI 写的内容应落进文件树里正确类型的文件（章节在正文、人物在角色……），而不是只留在
对话里；文件名与章节序号应连续。

### 套餐与额度

| 项 | 免费版 | Pro |
|---|---|---|
| AI 消息 | 每个北京时间自然日 10 条 | 不限 |
| 项目数 | 3 个 | 不限 |
| 素材库 | 不可用 | 可用 |
| 版本历史 | 每文件保留较少版本 | 更多 |

数字以页面实际展示为准；若页面上的数字与上表不一致，或同一页面不同位置的数字互相矛盾，
都记为问题。导出格式以页面为准（默认配置下为 txt）。

### 刻意的产品决定（不要记为 bug）

- **灵感库当前刻意关闭**：入口不可见或不可用是预期行为；但如果页面上仍有指向它的链接、
  文案或空页面，记为问题。
- **素材库是 Pro 功能**：免费用户被拦是预期；要评估的是拦截文案和升级路径是否清楚。
- 付款只支持支付宝。

### 术语表

| 术语 | 含义 |
|---|---|
| Pro | 付费订阅档 |
| 免费版 | 默认套餐 |
| AI 消息 | 用户向 AI 发出的一条消息，计入每日额度 |
| 订阅权益 | 当前套餐包含的额度与功能 |

页面上出现上表之外、新用户看不懂的术语（内部代号、英文变量名、原始 i18n 键），记为信息展示问题。
