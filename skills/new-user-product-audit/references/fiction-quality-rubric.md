# 写作产出质量评分表

对每个交付物按维度打 1–5 分，**每个维度都要附一段 50–150 字的原文摘录作为依据**。分数是给团队
比较版本用的，摘录才是让人信服的东西。

## 评分维度

| 维度 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| 任务完成度 | 完整交付，字数/章数/集数达标（±20% 以内） | 交付了但缺一块或字数明显不足 | 没写完、停在半截、交付物不对 |
| 连贯与衔接 | 情节因果清楚；跨章/跨集无断裂、无重复 | 偶有跳跃或复述上一章 | 前后矛盾、情节断裂 |
| 人物一致 | 名字、性格、能力、关系前后一致，有辨识度 | 有轻微漂移 | 改名、性格突变、关系错乱 |
| 节奏与钩子 | 开头抓人；章/集末有钩子；爽点或情绪点分布合理 | 平铺直叙，钩子弱 | 拖沓或仓促，无钩子 |
| 题材契合 | 符合所选题材的读者期待与平台习惯 | 题材元素有但不地道 | 跑题 |
| 行文自然度 / AI 味 | 读起来像人写的；对话有口语感 | 有零星套话 | 套话密集、排比堆砌、总结式结尾 |
| 格式 | 分段、对白、章节标题、剧本格式规范 | 小问题 | 格式错乱（小说写成提纲、剧本写成散文） |

**综合分** = 各维度平均，保留一位小数；任务完成度 ≤ 2 时，综合分上限为 2.5（没写完的东西写得
再漂亮也不能用）。

## AI 味检查清单

数一数出现次数，写进报告：

- 套话：不禁、心中一震、嘴角勾起一抹、眼中闪过一丝、仿佛、宛如、空气仿佛凝固
- 结构：每段都以总结句收尾；连续三段排比；“这一刻，他终于明白了……”式升华
- 对话：人物说话像念旁白；所有人同一种腔调
- 节奏：每章固定“冲突—解决—感悟”三段式；章末总有一句“然而，他不知道的是……”

## 长篇 / 多集的跨单元检查

写满多章或多集后额外核对：

- 人物表：列出每章出现的主要人物与其设定，看有无冲突
- 时间线：日期、季节、年龄、伤势是否连贯
- 伏笔：前面埋的线后面是否回收或至少没被遗忘
- 重复：第 N 章是否在复述第 N-1 章的事件或套用同一结构
- 递进：冲突是否升级，还是原地打转

## 与产品行为的关联

质量问题常常是产品问题，不只是模型问题。记录时尽量判断来源：

| 现象 | 可能的产品侧原因 |
|---|---|
| 后面章节忘了前面设定 | 上下文没带上角色/大纲文件，或带了但被截断 |
| 字数严重不足 | 产品没把字数目标传给 AI，或输出被截断 |
| 内容只在对话里、没进文件 | 写文件工具未调用或失败但未提示 |
| 改写覆盖了不该改的段落 | 编辑范围不受控，缺少对比/撤回 |

这类判断写成“推测”，放在报告「开放问题」里，让团队核实。
