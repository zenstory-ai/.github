# 写作产出质量评分表

对每个交付物按七个维度打 1–5 分，**每维必须附一段 50–150 字原文摘录佐证**。按任务约定的题材、篇幅和形式评判；偏安静或文学向作品不因缺少强悬崖卡点扣分。

| 维度 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| 任务完成度 | 完整收尾，字数/章数/集数在 ±20% 内 | 缺模块或字数明显缩水 | 半截断尾、未完待续或文体错误 |
| 连贯与衔接 | 因果清楚，跨章/跨集无断层与复述 | 偶有跳跃或开头复述上章 | 前后矛盾、主线断裂 |
| 人物一致 | 姓名、性格、能力、关系始终一致有辨识度 | 局部轻微漂移 | 串名、性格突变、关系错乱 |
| 节奏与钩子 | 开头抓人，冲突递进合理，章/集末卡点有力 | 平铺直叙，钩子偏弱 | 拖沓注水或仓促收尾 |
| 题材契合 | 踩中题材读者期待与平台习惯 | 有题材标签但不地道 | 跑题 |
| 行文自然度 | 像真人手写，对白符合角色口吻 | 零星套话 | 套话密集、排比升华泛滥、播音腔 |
| 格式规范 | 标题、分段、引号对白或剧本场次格式标准 | 个别排版小瑕疵 | 小说写成提纲、剧本写成散文 |

**综合分** = 七维平均（留一位小数）；**任务完成度 ≤ 2 时，综合分封顶 2.5**。

## AI 味巡检与跨章核对

结合上下文统计机械套路频次并摘例句（偶发单次正常用词不机械扣分）：
- **套话与微动作代偿**：`不禁`、`心中一震`、`嘴角勾起一抹`、`眼中闪过一丝`、`仿佛`、`空气仿佛凝固`，或满篇摩挲杯沿、垂眸停顿。
- **结构与对白套路**：段尾强行升华、三段排比、每章固定「冲突—秒解—感悟」、章末必接「然而他不知道的是……」、全员说明书腔调。
- **多章/多集附加核对**：核查人物设定表、日期伤势时间线、伏笔回收，以及第 N 章是否变相重写第 N−1 章结构。

## 由产出瑕疵反推产品疑点（记入报告「开放问题」供团队核实）

| 产出异常 | 推测的产品侧原因 |
|---|---|
| 后几章忘掉前文角色或大纲 | 请求未挂载角色/大纲文件，或上下文超长被截断 |
| 字数长期远低于目标 | 未把章字数约束传给 Agent，或输出被截断未续写 |
| 正文只吐在聊天框、没进文件树 | 写文件工具未调用或报错被吞 |
| 局部改写误伤前后正常段落 | 编辑器选区锚点未锁死，缺少对比撤回 |
