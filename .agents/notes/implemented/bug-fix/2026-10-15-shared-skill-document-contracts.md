# Agent Note: 共享技能文档与执行边界对齐

Status: implemented

## Problem

共享技能说明中，产品事实未包含现行免费素材试拆；一次性邮箱示例把含验证码的邮件写入运行日志，与报告保护要求冲突。截图、公开入口和私有信息的边界也有混用，发布写作说明对 shell 失败行为的解释不准确。

## Decision

逐文件依照 prose-gap-polish 五步流程精修当前文档，保留反例、配对示例和已声明的工作流。产品事实回查公开仓库实现；验证邮件保存在仓库与报告目录外的私有文件；保密要求约束私有地址和个人信息，保留任务需要的公开资源入口；发布步骤按现有脚本和真实 shell 行为说明。

## Alternatives considered

- 保留所有命令示例原样，只改外围说明：能最大程度避免示例漂移，但含验证码邮件仍会进入日志目录，执行结果与说明继续矛盾。
- 将所有示例和模板重新生成：能统一措辞，却会改动现有反例、数值和配对对照，超出本次精修需要。

## Consequences

共享指引与实际操作一致，读者能分清当前产品事实与测试观察。命令修正需重新进行语法和结构检查；本次不实际注册邮箱、发消息或修改产品数据。
